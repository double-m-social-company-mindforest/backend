====================================================
마인드포레스트 회원가입/로그인 기능 구현 계획
====================================================

1. 기능 요구사항
====================================================

1.1 회원가입
- 닉네임 (필수)
  * 중복 확인 기능 필요
  * 유니크해야 함
- 비밀번호 (필수)
  * 비밀번호 해싱 (bcrypt 사용)
- 비밀번호 재확인 (필수)
  * 프론트엔드에서 검증
  * 백엔드에서도 확인

1.2 로그인
- 닉네임으로 로그인
- 비밀번호 확인
- JWT 토큰 발급
  * Access Token (15분)
  * Refresh Token (7일)

====================================================
2. 데이터베이스 스키마
====================================================

테이블: users
- id: Integer, Primary Key, Auto Increment
- nickname: String(50), Unique, Not Null
- password_hash: String(255), Not Null
- created_at: Timestamp, Default NOW()
- updated_at: Timestamp, Default NOW()
- is_active: Boolean, Default True

테이블: user_refresh_tokens
- id: Integer, Primary Key, Auto Increment
- user_id: Integer, Foreign Key -> users.id
- token_hash: String(255), Not Null
- expires_at: Timestamp, Not Null
- created_at: Timestamp, Default NOW()
- is_active: Boolean, Default True

====================================================
3. API 엔드포인트
====================================================

3.1 회원가입 관련
POST /api/auth/signup
- Request Body:
  {
    "nickname": "string",
    "password": "string",
    "password_confirm": "string"
  }
- Response:
  {
    "status": "success",
    "message": "회원가입이 완료되었습니다",
    "data": {
      "user_id": 1,
      "nickname": "string"
    }
  }

POST /api/auth/check-nickname
- Request Body:
  {
    "nickname": "string"
  }
- Response:
  {
    "status": "success",
    "data": {
      "available": true/false
    }
  }

3.2 로그인 관련
POST /api/auth/login
- Request Body:
  {
    "nickname": "string",
    "password": "string"
  }
- Response:
  {
    "status": "success",
    "message": "로그인 성공",
    "data": {
      "access_token": "jwt_token_string",
      "refresh_token": "refresh_token_string",
      "token_type": "Bearer",
      "expires_in": 900
    }
  }

POST /api/auth/refresh
- Request Body:
  {
    "refresh_token": "string"
  }
- Response:
  {
    "status": "success",
    "data": {
      "access_token": "new_jwt_token_string",
      "token_type": "Bearer",
      "expires_in": 900
    }
  }

POST /api/auth/logout
- Headers:
  Authorization: Bearer <access_token>
- Response:
  {
    "status": "success",
    "message": "로그아웃 되었습니다"
  }

5. 구현 순서
====================================================

1단계: 데이터베이스 설정
- users 테이블 생성 마이그레이션
- user_refresh_tokens 테이블 생성 마이그레이션

2단계: 모델 생성
- User SQLAlchemy 모델
- UserRefreshToken SQLAlchemy 모델

3단계: 스키마 생성
- SignupRequest, SignupResponse
- LoginRequest, LoginResponse
- CheckNicknameRequest, CheckNicknameResponse
- RefreshTokenRequest, RefreshTokenResponse

4단계: 서비스 로직
- JWT 토큰 생성/검증 함수
- 비밀번호 해싱/검증 함수
- 회원가입 로직
- 로그인 로직
- 토큰 갱신 로직

5단계: API 라우터
- 회원가입 엔드포인트
- 닉네임 중복 확인 엔드포인트
- 로그인 엔드포인트
- 토큰 갱신 엔드포인트
- 로그아웃 엔드포인트

6단계: 미들웨어
- JWT 인증 미들웨어
- 현재 사용자 가져오기 의존성

7. 필요한 패키지
====================================================

- python-jose[cryptography]  # JWT 토큰 처리

8. 보안 고려사항 (구현 시 제외)
====================================================

사용자 요청에 따라 다음 보안 기능은 구현하지 않음:
- 비밀번호 복잡도 검증
- 로그인 시도 제한
- 계정 잠금
- 이메일 인증
- 2FA (Two-Factor Authentication)
- HTTPS 강제
- CORS 제한
